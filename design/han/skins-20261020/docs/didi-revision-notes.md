# 滴滴皮肤第二版：实车门贴参考与调整

日期：2026-10-20

## 这次调整

依据用户对下部橙色块和白色车底衔接不协调的反馈，使用内置 image_gen 编辑第一版白车：

- 删除整条大面积橙色下门板色块，让珍珠白车漆恢复连续。
- 下沿保持原厂风格的深色侧裙、黑色前唇和较细金属饰边，避免把白色、橙色、黑色切成几块。
- 将跨门的大号全橙字缩为前门上的单组标识：橙色 D 形标记＋深灰色「滴滴出行」，尽量留出完整车身线条。
- 保留汉 EV 的视角、轮胎位置、黑色车顶、透明画布和导出框。红色 PNG、WebP、高分辨率源文件 SHA-256 均与首版完全相同。

本设计采用检索到的真实车辆样例中的常见简洁视觉做法，不声称滴滴存在适用于所有车辆的统一车身涂装，更不将这张汉 EV 概念图当作真实官方车队照片。

## 复核

- 640×440、RGBA 真透明，PNG 与无损 WebP 解码后完全一致。
- 用首版固定裁切框 [28,145,1494,918]、缩放 620×327、偏移 [10,56]；没有单独重新缩放或居中红车。
- 已检查高分辨率源图，以及浅底/深底/棋盘背景和 180px 宽缩略图。
- 「滴滴出行」在 640px 成品可读；180px 时文字很小，界面仍应提供文字名称。
- AI 编辑有很小轮廓细节差异，修订白车与红车的高 Alpha 主体轮廓交并比约 99.27%，不是精确的 3D 材质换色。
- 保留第一版文件的 Library 历史版本；当前资源路径不变，仍为 static/vehicles/han/default.webp 与 didi.webp。
